## Installation

Requires Python 3.9 or later.

```bash
pip install tokensguru
# or
uv tool install tokensguru
```

Then check it works:

```bash
tokensguru --version
tokensguru info
```

### From a local clone

```bash
pip install .            # regular install
pip install -e .         # development (editable) install
```
